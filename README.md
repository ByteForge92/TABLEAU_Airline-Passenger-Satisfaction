# ✈️ Airline Passenger Satisfaction Dashboard

## 📊 Overview

This project analyzes airline passenger satisfaction using an interactive Tableau dashboard. It highlights key performance indicators, customer experience metrics, and travel patterns.

---

## 🚀 Key Insights

* Majority of passengers rate services as **Good (3–4)** (~51%)
* Business travel dominates (~69%)
* Overall satisfaction split:

  * Satisfied: ~43%
  * Neutral/Dissatisfied: ~56%
* Highest rated services:

  * Baggage Handling
  * Check-in Service
* Lower rated services:

  * In-flight WiFi
  * Seat Comfort

---

## 📌 Dashboard Features

* KPI Cards (Total Passengers, Avg Age, Delays)
* Age distribution histogram
* Ratings breakdown (Poor → Excellent)
* Service-wise rating comparison
* Travel type analysis
* Satisfaction segmentation
* Ticket class distribution

---

## 🛠 Tools Used

* Tableau Public
* CSV Dataset (Airline Passenger Satisfaction)
